# 区域拾音

本项目目录用于未来的区域拾音实现，目前还处于需求与实验准备阶段，尚无可运行算法。

## 规划资料如何串联

先在[方案总览](../../docs/area-pickup/overview.md)确定目标区域、麦克风阵列和评价约束；该文档还列出采样率、阵列几何、环境条件变化后需要复核的内容。随后用[实验记录](../../docs/area-pickup/experiments.md)记录每次采集和处理的参数、测点、指标与结论。当前目录没有代码参数可复习，具体算法与依赖将在形成可运行实验后记录。

## 开发顺序

1. 在 [`docs/area-pickup/overview.md`](../../docs/area-pickup/overview.md) 填写场景、拾音区域、阵列几何、通道同步和实时约束。
2. 设计一组可重复的录音与测量场景，使用 [`docs/area-pickup/experiments.md`](../../docs/area-pickup/experiments.md) 记录数据、参数、结果和限制。
3. 确认多通道数据格式、元数据字段和基线指标后，再增加 `src/`、采集/处理脚本和项目依赖清单。
4. 每个实现模块配套说明输入输出、采样率/通道假设、运行命令和最小复现实验。

原始录音、敏感元数据、模型检查点和大型数据集保存在仓库外。当前尚未建立独立依赖清单；开始有代码和稳定依赖后，再通过仓库统一的依赖同步入口生成项目清单。
