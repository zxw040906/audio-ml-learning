# 学习路线与记录

这个仓库按从信号表示到模型输入的顺序组织练习。每次新增主题时，记录问题、数据/参数、关键观察和下一步，不只保留代码。

## 已有内容

### 1. 神经网络计算基础

`learning/neural-network/` 从单个 Sigmoid 感知机开始，接着用 NumPy 权重矩阵演示多层前向传播，再通过 PyTorch 验证一维/二维卷积、padding/stride、池化和图片张量处理。当前多层网络未训练；CNN 示例主要验证张量维度与 TensorBoard 模型图。

### 2. 离散语音信号特征

`learning/speech-signal-processing/` 包含幅值包络、RMS、ZCR、手工和 librosa STFT、谱质心。重点是采样率、帧长、帧移、窗函数、频点到 Hz 的换算，以及手写实现与库函数的边界定义差异。现有谱带宽变量尚未计算，需要后续补齐。

### 3. PyTorch 音频管线

`learning/audio-deep-learning/` 演示 Tensor、YESNO Dataset/DataLoader、音频长度/采样率规范化、UrbanSound8K Mel 谱图和 TensorBoard 记录。下一阶段可在明确官方 fold 拆分后加入批训练、损失曲线、混淆矩阵和基线评估。

## 后续路线

1. 为信号特征统一时间轴和单位，在谱图/波形上叠加特征曲线，并记录手写与库实现差异。
2. 把教学脚本中顶层演示逐步提炼成可复用函数，同时保持小例子方便阅读。
3. 基于 UrbanSound8K 做规范的 train/validation/test 实验，记录 fold、随机种子、模型、指标和环境版本。
4. 区域拾音先完善场景、阵列几何、同步与通道数、采样参数、目标区域和评价指标，再开始算法比较。
5. 某方向形成稳定入口、独立依赖和维护节奏后，再考虑拆为独立仓库。
